# Releases

This repository hosts public release assets.

## Tag Organization

We structure our release tags using the following hierarchical format:

```text
MainApp/ModOrTweak/package-version-base-app-version
```

*   **First Component:** The name of the core application.
*   **Second Component:** The name of the third-party modification. If the package is an unmodified, stock app, this will just repeat the main app's name.
*   **Third Component:** The specific package version followed by the base app version.

> **Current Example:**
> `YouTube/lowiqentity/5.21-21.30`

Furthermore, to ensure easy identification, all release titles and asset filenames explicitly include the main app, the base app version, the package name, and the package version.
